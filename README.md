# Developer Portfolio

My personal portfolio: **[abdulkaleem-portfolio.vercel.app](https://abdulkaleem-portfolio.vercel.app)**

Built with **Next.js 15, React 19, TypeScript, Tailwind CSS 4 and Framer Motion**, and deployed on Vercel.

## Features

- Sections for hero, about, skills, experience, projects (with tech filters) and contact
- Animated scroll-progress bar and section transitions (Framer Motion)
- Contact form powered by EmailJS
- All content comes from one file, [`src/lib/data.ts`](src/lib/data.ts), so updates take one edit
- Responsive, with a floating call-to-action and a downloadable resume

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
```
